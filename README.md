# 근무 인수인계 · 일정관리

교대할 때 말로만 넘기다 빠뜨리는 것을 없애기 위한 **로컬 실행 인수인계·일정관리 프로그램**입니다.
병사(위병조장·당직병)뿐 아니라 간부·군무원 등 누구든 자신의 직책을 추가해 똑같이 쓸 수 있습니다.
`NotionFor7th.html` 파일 하나로 동작하며, 설치·인터넷 연결·회원가입이 필요 없습니다.

## 실행 방법

1. `NotionFor7th.html` 파일을 USB나 공용 폴더로 옮깁니다.
2. 파일을 더블클릭하면 브라우저(크롬·엣지 등)에서 바로 열립니다.
3. 처음 한 번만 부대명과 직책을 입력합니다.
4. 설정에서 **근무 구분**과 **기본 점검 항목**을 부대 실정에 맞게 등록합니다. 미리 채워진 예시는 없습니다.
5. 병사 외에 간부·군무원 등도 함께 쓰려면 설정 > **직책 관리**에서 필요한 만큼 직책을 추가합니다.

> 위병소·당직실 PC 바탕화면에 바로가기를 만들어 두고, 브라우저 즐겨찾기에도 등록해 두면 편합니다.
> 크롬이 기본 브라우저가 아니라면 파일 우클릭 후 연결 프로그램에서 Chrome을 선택하십시오.

## 무엇을 해결하나

간부가 같은 지시를 두 번 하게 되는 이유는 대부분 **"지시를 받은 사람"과 "일을 처리할 사람"이 다르기 때문**입니다.
이 프로그램은 지시사항을 사람이 아니라 기록에 붙여 둡니다.

- 지시사항을 등록하면 완료 처리 전까지 모든 인계서에 자동으로 포함됩니다. 인계자가 빠뜨려도 인수자 화면에 그대로 표시됩니다.
- 인계될 때마다 이월 횟수가 올라가고, 3회 이상 이월된 지시는 경고로 표시됩니다. 같은 지시가 반복되기 직전의 항목입니다.
- 지시사항마다 처리 이력(시각, 담당, 내용)이 남아 전달 여부를 확인할 수 있습니다.

## 주요 기능

| 화면 | 내용 |
|---|---|
| 홈 | 미처리 지시사항, 기한 경과, 반복 이월 경고, 다가오는 일정, 최근 인계 |
| 달력 | **월간/주간/일간 보기**, **반복 일정**(매일·매주·매월), 훈련·검열·면회 등 일정 등록, **한국 공휴일·대체휴일 자동 표시**, **음력 날짜**, **할 일 체크리스트**, **브라우저 알림** |
| 인계서 작성 | 점검 항목 체크 → 지시사항 인계 → 반드시 전달할 사항 → 특이사항 → 양측 확인 |
| 지시사항 | 지시 등록 및 상태 관리(진행 중 / 보류 / 완료), 처리 이력 |
| 인계 기록 | 지난 인계서 검색(날짜·이름·내용), 월별 정리 |
| 설정 | 부대명, **직책 관리**(추가·이름변경·삭제), 근무 시간대, 직책별 기본 점검 항목 편집, 알림, 백업 |
| 사용 설명서 | 교대 절차, 상황별 대처, 자주 나오는 실수 (인쇄해서 게시 가능) |

- 직책마다 각각 별도의 점검 항목·지시사항·인계 기록을 가집니다. 좌측 상단을 눌러 전환합니다.
- 병사(위병조장·당직병)가 기본으로 들어 있지만, 설정 > 직책 관리에서 간부·군무원 등 필요한 직책을 자유롭게 추가·삭제할 수 있습니다.
- 달력에 적은 일정은 홈의 「다가오는 일정」(일주일치)과 인계서의 「예정된 일정」(오늘·내일)에 자동으로 나타납니다.
- 야간 근무를 고려한 다크 모드를 지원합니다. (좌측 하단)
- 인계서는 인쇄할 수 있습니다. 서면 보관이 필요하면 그대로 출력해 서명하면 됩니다.

### v2.0 달력 기능 강화

- **한국 공휴일 표시** — 양력 고정 공휴일(신정, 삼일절, 어린이날, 현충일, 광복절, 개천절, 한글날, 성탄절) 및 음력 기반 공휴일(설날 연휴, 추석 연휴, 부처님오신날) 자동 표시
- **대체휴일 자동 계산** — 공휴일이 토·일요일에 겹치거나 공휴일끼리 겹칠 경우 대체휴일 자동 반영
- **음력 날짜** — 달력의 각 날짜에 음력 날짜 표시 (2024~2035년 데이터 내장)
- **할 일 관리** — 날짜별 할 일을 추가하고, 체크하면 취소선으로 완료 표시, 삭제 가능
- **색상 테마 리뉴얼** — 전체 UI를 핑크-퍼플 웜 톤으로 통일 (배경·텍스트·테두리·그림자까지 일관된 색감)

### v3.0 직책 확장 및 일정관리 강화

- **직책 자유 추가** — 위병조장·당직병 2개 고정 구조를 없애고, 간부·군무원 등 필요한 직책을 설정에서 자유롭게 추가·이름변경·삭제
- **반복 일정** — 일정을 매일/매주/매월 단위로 반복 등록. 반복 종료일 지정 가능
- **반복 일정 개별 수정·삭제** — 특정 날짜 하나만 예외로 두거나, 반복 전체를 한 번에 수정·삭제
- **주간/일간 보기** — 달력을 월간 외에 주간·일간 보기로도 확인
- **직책별 달력 필터** — 직책이 여러 개일 때 특정 직책의 일정만 걸러서 보기
- **브라우저 알림** — 탭을 열어 둔 동안 시간이 정해진 오늘 일정이 다가오면 알림 (설정에서 켜기)
- **일정 완료 체크** — 월간/주간/일간 보기에서 체크박스로 일정을 완료 표시(줄긋기)

### v3.1 편의 기능 및 내보내기

- **직책별 배지 색** — 직책마다 다른 색을 지정해 한눈에 구분 (설정 > 직책 관리)
- **일정 검색** — 달력 상단 검색창에서 제목으로 찾아 그 날짜로 바로 이동
- **일정 겹침 경고** — 같은 날 같은 시각에 일정이 겹치면 저장할 때 알려줌
- **다음 일정 위젯** — 상단바에 다음 일정과 남은 시간을 항상 표시, 클릭하면 그 날짜로 이동
- **.ics 내보내기** — 등록한 일정을 표준 캘린더 파일로 내보내 휴대폰 캘린더에서 확인
- **.csv 내보내기** — 인계 기록을 엑셀에서 바로 열리는 CSV로 내보내기 (감사·보고용)
- **백업 리마인더** — 마지막 백업 후 7일이 지나면 홈 화면에 알림 배너
- **직책별 할 일 구분** — 할 일에도 직책을 지정할 수 있어, 비워 두면 공통으로 모두에게 보임
- **키보드 단축키** — N(지시사항 등록), /(검색창 이동), T(오늘로 이동)

## 권장 운영 방법

1. 지시를 받은 즉시 「지시사항 등록」으로 남깁니다. 나중으로 미루면 그 자체가 누락입니다.
2. 교대 30분 전 「인계서 작성」으로 점검 항목을 하나씩 확인하며 채웁니다.
3. 인수자와 화면을 함께 보면서 지시사항을 확인합니다. 처리한 것만 「완료」로 바꿉니다.
4. 양측 이름을 확인하고 「인수인계 완료 처리」를 누릅니다.
5. 남은 지시사항은 다음 인계서로 자동 이월됩니다.

상세한 사용법은 프로그램 안의 **사용 설명서** 화면에 있습니다.
처음 투입되는 근무자에게는 그 화면을 인쇄해 근무 위치에 붙여 두는 것을 권장합니다.

## 데이터 저장과 백업 — 꼭 읽어 주세요

- 모든 데이터는 그 컴퓨터의 그 브라우저 안에만 저장됩니다. 외부로 전송되지 않습니다.
- 따라서 브라우저 기록·쿠키·사이트 데이터를 삭제하면 함께 지워집니다. 시크릿 모드에서는 저장되지 않습니다.
- 다른 PC에서 이어서 쓰려면 설정에서 백업 파일(`.json`)을 내려받아 옮긴 뒤 불러오기 하면 됩니다.
- 주 1회 이상 백업 파일을 받아 두는 것을 권장합니다. 7일 넘게 백업하지 않으면 홈 화면에 알림 배너가 뜹니다.
- `.json` 백업은 이 프로그램에 다시 불러올 수 있는 전체 백업이고, `.ics`(일정)·`.csv`(인계 기록)는 다른 프로그램에서 보기 위한 **내보내기 전용**입니다 — 이 둘로는 복원할 수 없습니다.

## 개인정보 관련 주의

계급·성명 등이 기록되므로, 공용 PC에 둘 경우 부대 규정에 따라 관리하시기 바랍니다.
군사 보안에 해당하는 내용(부대 편성, 암구호, 상세 경계 계획 등)은 이 프로그램에 입력하지 마시고,
규정에 따른 별도 문서로 관리하십시오.

## 파일을 갱신했는데 화면이 그대로일 때

크롬은 `file://`로 연 파일도 캐시합니다. **Ctrl + Shift + R**(맥은 Cmd + Shift + R)로 강력 새로고침 하십시오.
설정 화면 맨 아래 버전 번호로 갱신 여부를 확인할 수 있습니다.

## 기술 사항

- 외부 라이브러리·CDN·서버 없음. 순수 HTML/CSS/JavaScript 단일 파일.
- 저장소: 브라우저 `localStorage` (키: `shdex.handover.v1`)
- 크롬·엣지·파이어폭스·사파리 최신 버전에서 동작합니다.
- 색상 테마: 핑크-퍼플 웜 톤, CSS 변수 기반 라이트/다크 모드
